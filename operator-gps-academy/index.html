Lesson 1: Getting started with machine control

Machine control combines a digital design, position sensors, and a display to help an operator compare the machine's working position with the intended grade.

Before work, confirm the correct project and design are loaded, verify the machine configuration and calibration, and check control points using approved site procedures. Never rely on the display alone for safe digging or utility clearance.
