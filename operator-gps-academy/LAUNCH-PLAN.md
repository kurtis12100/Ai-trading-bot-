# Operator GPS Academy — launch plan

This is the planning document for a paid training platform. The existing public demo is in `operator-gps-academy/index.html`.

## Courses
- **Foundation — six hours:** narrated, operator-view lessons on machine control setup, project/design selection, site control checks, cut/fill, offsets, stations, grade verification, sensor troubleshooting, and safe work practices. Include realistic machine demonstrations and short knowledge checks.
- **Intermediate — two days:** detailed workflows for dozer, excavator, and loader applications; design discrepancies; calibration and verification; supervised exercises.
- **Advanced — one week:** project files, complex grading, diagnostic case studies, practical assessments, and instructor review.

## Website and security
The GitHub Pages demo is **public**. Do not store paid lessons, passwords, customer records, payment keys, or private videos in this repository. Use a managed course platform or a proper authenticated backend with server-side entitlements and private video delivery. Payments must use a PCI-compliant hosted checkout. Never rely on hidden links or client-side JavaScript to restrict paid access.

## Launch sequence
1. Verify GitHub Pages deployment from Settings > Pages (source: main branch, root), and verify the live URL `https://kurtis12100.github.io/Ai-trading-bot-/`.
2. Keep the existing site as a free preview and outline/course catalogue.
3. Produce the first narrated module, validate machine-control accuracy with experienced operators, and expand to the six-hour curriculum.
4. Select hosted course software, connect a payment processor, and test registration, purchase, login, refund, and access revocation.
5. Publish paid content only after authentication, payment, accessibility, privacy, and video delivery have been tested.

**Status:** Planning document only. No paid login, payment processing, or six-hour narrated video has been deployed.
